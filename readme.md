# Memories Relive

Some journeys end. Their memories never do.

An interactive 3D Rishikesh and Bhai Dooj memory adventure for Ishaan.

## The Story
From Kitaabi Dastaan to a memorable journey through Rishikesh.

## Journey
- Interactive 3D mountain environment
- Scooter riding and exploration
- Maggi and chai stops
- Neelkanth and Baal Kuari memories
- Interactive Bhai Dooj finale

## Tech Stack
Next.js, TypeScript, Three.js, React Three Fiber

## Status
Existing playable Next.js game, refined in place. See [refinement QA](REFINEMENT_QA.md) for implementation, validation and verification limits, and [private media setup](PRIVATE_MEDIA_SETUP.md) for server configuration.

Run `npm run dev` for local development. Validate with `npm run typecheck`, `node --test tests/*.test.cjs`, and `npm run build`. There is no configured lint command.

Keep private originals, access codes and server credentials out of Git. Product branding does not rename the Vercel project or domain; those remain separate dashboard settings.
